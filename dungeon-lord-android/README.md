# 마왕의 던전 — 안드로이드 앱

게임 HTML 한 장을 WebView로 띄우고, 광고는 안드로이드 쪽 애드몹 SDK가 처리합니다.
Capacitor·Cordova 같은 중간 도구가 없어서 구조가 단순하고 앱 용량도 작습니다.

```
.github/workflows/build.yml     깃허브에서 APK를 대신 빌드해 주는 설정
android-app/
  app/src/main/
    assets/index.html           게임 본체 (이 파일만 갈아끼우면 게임이 업데이트됨)
    java/.../MainActivity.java  WebView + 애드몹 연결
    AndroidManifest.xml         앱 권한, 애드몹 앱 ID
    res/mipmap-*/               런처 아이콘
  app/build.gradle              앱 설정 (패키지명, 버전)
```

---

## 폰만으로 APK 뽑기

안드로이드 앱을 빌드하려면 안드로이드 SDK가 필요한데, 폰에 깔기엔 무겁습니다.
그래서 **깃허브가 대신 빌드하게** 해 뒀습니다.

1. 깃허브에 새 저장소를 만들고 이 폴더를 통째로 올립니다 (`main` 브랜치)
2. 올리면 빌드가 자동으로 돕니다. 저장소의 **Actions** 탭에서 진행 상황이 보입니다
3. 초록색 체크가 뜨면 그 실행을 눌러 맨 아래 **Artifacts → dungeon-lord-debug** 를 내려받습니다
4. 압축을 풀면 `app-debug.apk` 가 나옵니다. 폰에서 그대로 설치하면 됩니다
   (설정에서 "출처를 알 수 없는 앱 설치"를 켜야 할 수 있습니다)

처음 빌드는 5~10분쯤 걸립니다. 그 다음부터는 더 빠릅니다.

게임을 수정했으면 `android-app/app/src/main/assets/index.html` 만 새 파일로 바꿔서
다시 올리면 됩니다.

## 광고 설정

지금은 **구글이 제공하는 테스트 광고**가 들어가 있습니다. 그대로 두면 가짜 광고가 나오고
수익은 발생하지 않습니다. 개발 중에는 이 상태가 맞습니다.

> 주의: 실제 광고 단위를 넣고 본인이 광고를 누르면 애드몹 계정이 정지될 수 있습니다.
> 출시 직전에만 바꾸고, 바꾼 뒤에는 본인이 광고를 누르지 마세요.

실제 광고로 바꾸려면 애드몹(admob.google.com)에서 앱을 등록하고 세 군데를 고칩니다.

| 바꿀 값 | 파일 | 현재 (테스트용) |
|---|---|---|
| 앱 ID | `AndroidManifest.xml` | `ca-app-pub-3940256099942544~3347511713` |
| 보상형 광고 단위 | `MainActivity.java` | `ca-app-pub-3940256099942544/5224354917` |
| 전면 광고 단위 | `MainActivity.java` | `ca-app-pub-3940256099942544/1033173712` |

패키지 이름도 `com.dungeonlord.game` 에서 본인 것으로 바꾸세요
(`app/build.gradle` 의 `applicationId`, `namespace`). 한 번 출시하면 다시 못 바꿉니다.

## 게임 안에서 광고가 나오는 자리

| 자리 | 종류 | 보상 |
|---|---|---|
| 로비 | 보상형 | 수정 150개, 하루 5회 |
| 전투 패배 후 | 보상형 | 수호석 50% 회복하고 이어하기 (판당 1회) |
| 전투 종료 후 | 보상형 | 획득 수정 2배 |
| 전투 3판마다 | 전면 | — |

게임 쪽은 `window.AndroidAds` 가 있으면 진짜 광고를, 없으면 **모의 광고**를 띄웁니다.
그래서 브라우저에서 열어도 광고 동선을 그대로 확인할 수 있습니다.

## 구글 플레이에 올릴 때

플레이에는 APK가 아니라 **서명된 AAB**를 올려야 합니다.

1. 서명 키를 만듭니다 (PC나 Termux에서 한 번만)
   ```
   keytool -genkey -v -keystore dungeon.jks -keyalg RSA \
           -keysize 2048 -validity 10000 -alias dungeon
   ```
   **이 파일과 비밀번호를 잃어버리면 앱을 영원히 업데이트할 수 없습니다.** 꼭 따로 보관하세요.

2. 키를 글자로 바꿉니다
   ```
   base64 -w 0 dungeon.jks
   ```

3. 깃허브 저장소 **Settings → Secrets and variables → Actions** 에 4개를 등록합니다
   - `KEYSTORE_BASE64` : 위에서 나온 긴 글자
   - `KEYSTORE_PASSWORD` : 키 저장소 비밀번호
   - `KEY_ALIAS` : `dungeon`
   - `KEY_PASSWORD` : 키 비밀번호

4. **Actions → APK 빌드 → Run workflow** 를 눌러 실행하면
   `dungeon-lord-release-aab` 에 서명된 AAB가 나옵니다

시크릿을 등록하지 않으면 서명 없는 파일이 나오고, 그건 플레이에 올릴 수 없습니다.

## 아직 안 된 것

- **이 프로젝트는 실제로 빌드해 본 적이 없습니다.** 만든 환경에 안드로이드 SDK가 없어서
  문법 검사(XML·YAML)까지만 했습니다. 첫 빌드에서 오류가 날 수 있고, 그때 로그를 주시면
  고쳐 드릴 수 있습니다.
- 스토어 등록용 그래픽(스크린샷, 피처 그래픽 1024×500, 앱 설명)
- 개인정보처리방침 — 광고를 넣으면 플레이가 **반드시** 요구합니다. 광고 식별자를 쓴다는
  내용이 들어가야 하고, 웹에 올려서 그 주소를 등록해야 합니다
- 데이터 안전성 양식 — 플레이 콘솔에서 "광고 ID 수집"을 신고해야 합니다
